# بهینه‌سازی و بازطراحی منوی عمومی

نسخه عمومی از نظر UI و performance از پایه بازطراحی شده است، بدون تغییر در قرارداد API.

## تغییرات اصلی

- حذف هویت بصری و نام نمایشی قبلی؛ صفحه به‌عنوان یک منوی عمومی و بدون برند ارائه می‌شود.
- طراحی mobile-first و ریسپانسیو از عرض 320px به بالا.
- دسته‌بندی‌های قابل اسکرول افقی و search field با tap target مناسب موبایل.
- کارت‌های منو با hover/press ظریف، lazy loading تصویر و placeholder سبک.
- modal جزئیات برای مشاهده آیتم بدون تغییر مسیر صفحه.
- انیمیشن‌ها فقط با CSS و همراه با `prefers-reduced-motion`.
- حذف وابستگی اجباری به فونت خارجی و استفاده از font stack سیستمی برای کاهش درخواست‌های شبکه.
- نگه‌داشتن cache محلی، refresh هنگام focus/visibility و fallbackهای فعلی.

## قرارداد داده و API

مسیرهای `/api/menu`، fallback و ساختار `menu.json` حفظ شده‌اند. بنابراین این بازطراحی قرار نیست منطق انتشار، ذخیره یا دریافت محتوا را تغییر دهد.
